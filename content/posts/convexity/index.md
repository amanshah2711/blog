## Topological Notions
These are all notions that exist when given a topology on the space, or defined specifically for convex sets in finite dimensions. We say a convex set is,

- open if for every $x\in C$, for every $d \in V$, $x + \mu d \in C$ for $\mu$ sufficiently small.
- closed if when $\mu x + (1-\mu)y$ is in $C$ for $\mu \in (0,1)$ then $x,y$ are in $C$.
- bounded if the $C$ contains no rays.
- relatively open if open when $d$ only takes on values in the affine hull of the set

Defined notions,
 
- interior
- relative interior
- boundary
- relative boundary
