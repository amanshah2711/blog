## Definition
A map, $\mathbf{L}(\cdot)$, between vector spaces $\mathbf{V}$ and $\mathbf{W}$ is called a *linear map* if it satisfies the following two properties,
1. $\mathbf{L}$ is homogeneous, that is $\mathbf{L}(\mu \mathbf{x}) = \mu \mathbf{L}(\mathbf{x})$.
2. $\mathbf{L}$ is additive, that is $\mathbf{L}(\mathbf{x}+\mathbf{y}) = \mathbf{L}(\mathbf{x}) + \mathbf{L}(\mathbf{y})$

### Intuition about the definition
Possible for non-bijective collineations, that preserve parallelism and fix the origin to be general linear maps. \
\
Fundamental theorem of projective geometry implies that all collineations are a combination of projective transformations with some field automorphism(R has trivial field automorphism).


Remark on notation: It is common to see linear maps being applied to an input written $\mathbf{L}\mathbf{x}$ instead of $\mathbf{L}(\mathbf{x})$.
